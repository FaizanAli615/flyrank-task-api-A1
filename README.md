# FlyRank Task API

A simple CRUD API built with Python and FastAPI for the FlyRank Internship Backend Track Week 2 Assignment A1.

## Features

- Get all tasks
- Get a single task
- Create a task
- Update a task
- Delete a task
- Input validation
- 404 handling for unknown tasks
- Swagger UI documentation
- In-memory data storage

## Technologies

- Python
- FastAPI
- Uvicorn
- Pydantic
